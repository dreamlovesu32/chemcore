# 色谱板与凝胶电泳对象规则

## 入口

- 左侧主工具栏只保留一个 TLC 板图标，代表色谱板工具组。
- 激活后，上方次级工具栏必须同时显示 **TLC Plate** 与
  **Gel Electrophoresis Plate**；切换子工具不改变左侧工具组。
- 两个子工具共享颜色入口，但创建结果必须是不同的原生语义对象。

## 对象边界

### TLC

- TLC 板仍对应 CDXML 的 `tlcplate/tlclane/tlcspot`。
- 板负责边界、起点线、溶剂前沿、边框、侧刻度和默认样式。
- 泳道负责顺序和可见性；斑点负责 `Rf`、宽高、拖尾、曲线类型、
  颜色、透明度、显示值、可见性和层级。
- 拖动斑点只修改 `Rf`；移动、缩放或旋转整板不改 `Rf`。

### 凝胶电泳

- 凝胶板对应 CDXML 的 `gepplate/geplane/gepband`，并在 CCJS 中使用
  `payload.gelElectrophoresis` 明确存储，不放进通用 `extra`。
- `gepplate` 是板；`geplane` 是拥有条带的泳道；`gepband` 是条带。
  这是父子所有权，不建立 Link 关系。
- 条带位置由 `BandValue`、`StartRange`、`EndRange` 和 `UnitID`
  共同决定。拖动条带修改 `BandValue`，不把画布像素写回为语义值。
- `UnitID=3` 的距离轴随数值向下增大；其他已知质量轴随数值向上增大。
  未知 `UnitID` 原值往返，不静默改写为其他单位。
- `Width`、`Height` 是条带自身尺寸；`alpha` 是条带强度/透明度；
  `CurveType` 决定端部轮廓，未知值原样保存。

## 几何与编辑

- 板的局部 `bbox` 是当前编辑几何。CDXML 四角坐标以局部 `corners`
  保存，用于保留非矩形板；编辑后由当前几何重新导出。
- 选择工具可整体移动、缩放和旋转板。整板变换不改变泳道数、`Rf`
  或 `BandValue`。
- 在色谱板工具或选择工具下，斑点/条带均可直接聚焦和纵向拖动。
  拖动进入一次撤销记录，预览不增加文档版本。
- 隐藏泳道仍占有原泳道序号和横向位置；隐藏条带不参与命中测试。

## 绘制与往返

- GUI、SVG、PNG 与 EMF 必须消费同一组内核绘制原语。
- TLC 的每个斑点必须应用自己的宽、高、颜色、透明度、可见性和
  `ShowRf`；不得退回板级颜色覆盖。
- 凝胶板必须应用边框、透明背景、泳道标签、条带宽高/强度/颜色、
  数值标签和标尺。
- CDXML 导入、CCJS 保存和 CDXML 导出均不得丢失官方字段。CDX
  仅在官方对象标签存在且经过验证时支持；否则明确拒绝，禁止静默降级。

## 验收

- 左侧入口及上方两个子工具有前端回归测试。
- TLC 公开夹具覆盖字段往返、绘制和 `Rf` 拖动。
- 凝胶夹具覆盖板范围、单位、泳道、条带值、宽高、强度、颜色、
  标签、标尺、拖动和 CDXML 二次解析。
- 板缩放、旋转以及 SVG/EMF 输出需走全量门禁。
