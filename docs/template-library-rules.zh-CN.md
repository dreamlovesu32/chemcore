# 模板库规则

TemplateGrid 的字段单位、槽位归属、编辑、CDX/CDXML 往返和门禁规则见
[TemplateGrid 原生模型、编辑与往返规则](template-grid-rules.zh-CN.md)。本文件其余部分描述模板内容的解析、放置和对象守恒。

## 目标与交互

模板库是独立的绘制模式，不在左侧再增加一条永久栏：

- 左侧主绘制栏底部的模板按钮负责进入模板模式；
- 顶部二级工具栏按库展示，一库一按钮；
- 点击库按钮打开可搜索的模板选择弹窗；
- 弹窗支持最近使用和收藏；
- 选择模板后进入连续放置状态，画布上每次点击放置一次，切换工具或按
  `Escape` 退出；
- 模板图标只由 ChemSema 内核从模板对象实时绘制，不保存第三方预览图，
  因而与画布渲染使用同一条规则链。

这样既不会长期占用第二条左栏，也允许模板库继续增加而不挤压主工具。

## 来源与分发边界

`scripts/extract-chemdraw-template-libraries.mjs` 从用户本机已授权安装的
ChemDraw Items 目录读取模板。当前用 ChemDraw 21 的本机安装验证得到 29
个库、881 个非空模板。

ChemDraw 自带模板可能受第三方许可约束，因此：

- 仓库提交解析、放置、渲染、门禁和提取脚本；
- `viewer/template-libraries/catalog.json` 与生成的 `.cdxml` 均只保留在
  本机并由 `.gitignore` 排除；
- ChemSema 不把 ChemDraw 的模板资源作为 Apache-2.0 项目内容再分发；
- 未生成本地目录时，模板模式明确显示不可用，不使用内置替代模板或静默
  fallback。

生成与复核命令：

```powershell
npm run generate:chemdraw-template-libraries
npm run gate:template-libraries
```

## 库与模板识别

提取器将每个源库转换为一个独立 CDXML：

1. 根级、非空 `page` 是一个模板；
2. 没有子对象的补位页不生成模板；
3. 页内 `annotation` 的 `Keyword=Name` 是规范名称；
4. 源文件未提供名称时，仅使用稳定的库内序号作为 UI 标签，不推测化学
   名称；
5. 图标由该页转换出的 CCJS 文档经内核 SVG 渲染生成。

## 放置规则

### 空白画布

模板的几何包围盒中心对齐点击点。模板的源文档键长先统一缩放到目标文档
键长，所有几何对象、文本和线宽使用同一缩放变换。

### 原子端点

仅分子模板参与原子融合：

1. 模板中第一个源节点是连接节点；
2. 源连接节点与目标原子合并，模板内对该节点的引用全部改写到目标原子；
3. 目标原子只有一个邻居时，模板首键按该键的精确 180° 延长线定向；
4. 有多个邻居时，在已有键方向之间选择最大空角的中心方向；
5. 没有邻居时保留模板原方向。

这是一条拓扑与角度规则，不按具体模板名称分支。

### 化学键

仅分子模板参与化学键融合：

1. 模板的第一根源键是融合键；
2. 源键两端映射到目标键两端，按使剩余模板变换最小的方向确定正反；
3. 删除模板首键及其两个源端点，保留目标键及目标键级；
4. 所有分子立体、反应、跨中心、着色区域、链接和场景载荷中的对象引用
   同步重映射。

非分子模板点击原子或键时不虚构化学连接，仍按点击点居中放置。

## CDXML 对象守恒

模板导入和重新导出必须遵守以下规则：

- `page`、`fragment`、`n`、`b`、`t`、`s`、`group` 使用明确的结构身份
  合并；
- `graphic`、`curve`、`arrow`、`bioshape` 不允许仅凭同名顺序配对；
- 有 ID 的场景对象按 ID 替换；
- 无 ID 曲线按 `CurvePoints` 的稳定指纹识别；
- 原生已解析对象从保留的 interchange 载荷中剔除，再由当前内核状态重新
  生成，避免重复；
- 未被内核建模的属性和子对象仍通过 interchange 原样保留；
- 曲线位于 group 内时必须记录其 group 归属。

## 完整目录门禁

`template_library_gate` 对本机目录内每个模板执行：

1. CDXML 解析；
2. 非空且有界的渲染；
3. 内核 SVG 图标生成；
4. CCJS 序列化；
5. CDXML 回写；
6. `fragment`、`n`、`b`、`t`、`graphic`、`curve`、`arrow`、
   `bioshape`、`group` 的语义对象计数守恒。

失败时把最小失败文档写入
`target/template-library-gate-failure.cdxml`。门禁不跳过坏模板，也没有
“无法解析则显示原预览图”的替代路径。

## 已验证边界

- ChemDraw 21 本机目录：29 个库、881 个模板；
- 全目录解析、内核绘制、CCJS、CDXML 往返与对象守恒；
- 空白放置、单邻居原子 180° 接续、多邻居最大空角、键融合；
- 目标文档键长缩放；
- 分子立体、跨中心、着色区域、链接、化学属性、反应方案和场景载荷引用
  重映射；
- 浏览器真实页面中的库切换、搜索、模板选择、连续放置与撤销。

当前交互采用点击放置，不实现 ChemDraw 的按压拖拽角度手势；这是明确的
产品交互边界，不是解析或渲染 fallback。
